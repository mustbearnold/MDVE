# Triage Labels

The skills use five canonical triage roles. This file maps those roles to the strings used by MDVE's local Markdown tracker.

| Label in mattpocock/skills | Label in MDVE     | Meaning                                  |
| -------------------------- | ----------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`    | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent` | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human` | Requires human implementation            |
| `wontfix`                  | `wontfix`         | Will not be actioned                     |

When a skill mentions a triage role, use the corresponding MDVE value from this table as the issue's `Status:` value.

Edit the right-hand column if MDVE adopts a different vocabulary later.
